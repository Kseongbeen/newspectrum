# 뉴스펙트럼 (NewSpectrum)

**한국의 언론 이념 편향 분석과 관점 비교 서비스 「뉴스펙트럼」 제안**

한국언론진흥재단 조사 원자료(언론인 조사 · 언론수용자 조사 · 10대 청소년 미디어 이용조사)를 재분석해
한국 언론의 이념 편향 구조를 공급·유통·수요 세 층위에서 진단하고, 기사 단위 관점 비교 서비스 「뉴스펙트럼」을 제안한 보고서와
그 분석·시연 코드 전체를 담은 저장소입니다.

- 보고서 최종본: [`보고서/한국의 언론 이념 편향 분석과 관점 비교 서비스 뉴스펙트럼 제안.pdf`](보고서/) (15쪽, hwpx 원본 동봉)
- 실데이터 시연 페이지: `뉴스펙트럼_시연.html` (자립형 — 내려받아 브라우저로 바로 열림)
- 인터랙티브 목업: `자료/그림5-3_화면설계_목업.html`

### 저장소에 포함하지 않은 것

| 항목 | 이유 |
|---|---|

| 재단 발간 보고서·통계표·코드북 PDF | 제3자 저작물, 재단 홈페이지에서 공개 배포 중 |

## 분석 재현 방법

**1. 실행 환경**

```
Python 3 + numpy, pandas, pyreadstat, scipy, matplotlib
한글 글꼴: 맑은 고딕 또는 나눔고딕 (그림 렌더링용)
```

**2. 원자료 준비 (필수)**

원자료는 저장소에 포함하지 않았습니다. 한국언론진흥재단([kpf.or.kr](https://www.kpf.or.kr))에서 아래 3종을 받아
**저장소 최상위 폴더에 아래 파일명 그대로** 두어야 스크립트가 인식합니다.

| 필요한 파일명 | 조사 | 용도 |
|---|---|---|
| `[로데이터] 2025 언론인 조사 원본 데이터.SAV` | 2025 한국의 언론인 | 4.1절 (공급), 표 4-1 |
| `3. 2025 언론수용자 조사_최종데이터.SAV` | 2025 언론수용자 조사 | 4.2·4.3절 (유통·수요), 표 4-2 |
| `2025 10대 청소년 미디어 이용조사_데이터.xlsx` | 2025 10대 청소년 미디어 이용조사 | 4.2.3절 (청소년) |

**3. 메인 분석 실행**

```
python 분석_뉴스펙트럼.py
```

- `분석_결과/그림/` 에 보고서 수록 그림 11개를 생성합니다. (그림 5-1·5-3은 HTML 목업을 캡처한 정적 이미지라
  이 스크립트가 재생성하지 않습니다 — `자료/`의 원본 HTML 참조)
- `분석_결과/분석_통계_재현.json` 에 본문 인용 통계 31개의 재현 값을 기록합니다.
- 그중 24개는 본문 수치와 자동 대조하며, 전부 일치하면 **종료 코드 0**을 반환합니다.
- 그림 5-2(파일럿 스탠스 분포)는 파일럿 산출물(`자료/파일럿/파일럿_결과.json`)에서 재현합니다.
- `그림/`·`자료/분석_통계_재현.json`은 이미 그 산출물의 확정본이며, 재실행 결과는 `분석_결과/`에 따로 생성됩니다
  (`.gitignore` 처리).

**4. 파일럿 보조 스크립트 (선택)**

```
python 파일럿_SBERT.py
```

문장 임베딩(SBERT, `ko-sroberta-multitask`) 기반 스탠스 판정을 재현하며 `자료/파일럿/파일럿_SBERT결과.json`을
생성합니다(입력 원문도 같은 폴더에서 읽습니다). 최초 실행 시 SBERT 모델(약 400MB)을 자동 다운로드합니다.

**5. 시연 페이지 재생성 (선택)**

```
python 시연_생성.py
```

`.streamlit/secrets.toml`에 네이버 뉴스 검색 API 키를 직접 발급받아 넣어야 합니다.

```toml
NAVER_CLIENT_ID = "..."
NAVER_CLIENT_SECRET = "..."
```

열람만 할 때는 `뉴스펙트럼_시연.html`을 그대로 열면 됩니다. `news_balance_app.py`(Streamlit 프로토타입)는
동일한 키를 환경변수 또는 `st.secrets`에서 읽습니다.

## 검증 — 2차 수치 재검증 완료 (2026-07-22)

보고서 최종본에 인용된 수치를 원자료에서 전부 재계산하여 대조했습니다. **불일치 0건.**

- **`분석_뉴스펙트럼.py` 자동 대조 24개 항목**: 전부 일치, 종료 코드 0.
  (개인·조직 이념 격차 +1.05·t=17.49, 격차 2점·3점 이상 비율, 광고주 64.5%, Q84/Q92/Q93/Q56/Q91 각 문항,
  BQ7×Q84 카이제곱 340.5, 청소년 TV·홈페이지 비율, 파일럿 일치율 46.7%·정반대오류 0건)
- **스크립트 자동 대조 대상 밖 항목**을 원자료에서 직접 재계산해 추가 확인:
  - Q95 직업군별 신뢰도(언론인 3.08점, 10개 중 5위, 교육자 3.48·의료인 3.52) — 일치
  - 그림 4-9 (BQ7×Q84G 교차, 성향별 텔레비전·포털·동영상 비율) — 일치
  - 그림 4-10 (Q91_4 편파 인식, 진보 58.2%·중도 58.7%·보수 61.2%) — 일치
  - 청소년 온라인 동영상 플랫폼 이용자 중 유튜브·쇼츠·릴스 이용률(95.1%·79.1%·64.0%,
    **가중치 WT 적용 필수** — 비가중 계산 시 94.6%·79.9%·64.9%로 소폭 어긋남) — 가중 계산으로 일치 확인
  - 파일럿 5.4절 "앵커 언론사 9건 중 반대 진영 분류 1건" — `파일럿_결과.json`의 anchor 필드는 부호 불일치
    기준 3/9를 담고 있으나, 보고서 5.2절이 정의한 중립 밴드(|점수|<1/3)를 적용해 재분류하면 진짜 반대 진영
    (P↔C) 전환은 1건(경향신문 스트레이트 기사)뿐 — 보고서 수치가 맞으며, JSON의 `misclass_rate`는 더 느슨한
    보조 지표입니다
- **표 4-2(가장 영향력 있는 언론사·매체)**: 원자료 비공개 문항이라 재계산 대상이 아니며, 공표 통계표(191쪽)
  값을 상수로 사용 — 스크립트 내 상수값과 보고서 표 값이 일치함을 확인

## 주요 참고 사항

- 언론수용자 조사·10대 청소년 조사 집계에는 각각 인구비례 가중치(WT)를 적용했습니다 (보고서 3.2절).
- 표 4-2는 공표 통계표 값을 상수로 사용했습니다 (원자료 문항 비공개 항목).
- `뉴스펙트럼_시연.html`의 기사 좌표는 언론사 단위 좌표를 잠정 적용한 것이며(기사 단위 스탠스 엔진은 5장
  파일럿 참조), 관점 종합은 성향권별 기사 제목·요약문에서 추출한 변별 키워드·대표 문장 인용(추출 요약)입니다.
- 파일럿 실험 절차와 3개 방법(TF-IDF·SBERT·LLM) 비교는 보고서 5장 참조. LLM 판정은 비독립(non-blind)
  예비 실험으로 일치율은 상한 추정치입니다.
